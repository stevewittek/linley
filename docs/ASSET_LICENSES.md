# Asset provenance

DemoSun, DemoBlue, DemoCoral, DemoPaper and DemoMotion are original geometric demo artwork generated by scripts/generate-demo-media.sh for this repository. Those demo samples contain no third-party photographs, children's media, music, characters or trademarks. Creator names refer to fictional sample profiles. Netherwood Data Partners may use these newly authored samples in Linley. Bundled third-party game audio is listed below.

Existing LinleyMark and AppIcon are retained unchanged from repository main at 43b224379802b575bf2a85fbc7a79cc2a4cc2221. No new rights or third-party provenance claim is made about pre-existing branding. Confirm brand asset rights before distribution. Interface symbols use Apple's SF Symbols through native system APIs.

ffmpeg is a development-only tool for fixture generation and audio conversion; it is not bundled or linked into the app.

Creative Quest uses original native SwiftUI vector artwork and Apple's SF Symbols; no third-party game source or visual assets were copied. QuestLorelei and QuestHailey are parent-requested illustrated character assets generated with the built-in imagegen tool from the supplied reference. The original photograph is excluded. See CHARACTER_ART.md for prompts, asset paths and pending family/release review. The concept image is a labeled design proposal, not app imagery or a verified screenshot.

Verified and downloaded October 17, 2026 from the creators' asset pages. These freely reusable audio assets are bundled locally; the app does not fetch them at runtime.

The upstream [License.txt](licenses/Kenney-Interface-Sounds.txt) is retained.
- [CC0 legal text](licenses/CC0-1.0.txt) and [original downloads, transformations and SHA-256 manifest](licenses/quest-audio-provenance.json) are retained. In-app Game Sound credits identify both creators. Audio files are open assets, not an open-source game-engine dependency. No external game code was introduced.
