# Dad-approved contribution workflow

Linley welcomes ideas from Lorelei and her invited testers, but children do not receive developer accounts, repository access, publishing access, or production credentials.

1. A child writes a feature card in the app or explains the idea to Dad.
2. Dad reviews the idea for safety, privacy, cost, and fit.
3. An approved idea becomes one high-level GitHub issue or milestone.
4. Development happens in a reviewed branch or supervised local session.
5. Dad and Lorelei test the result on an iPad.
6. Dad decides whether it is accepted, revised, or held for later.

ChatGPT may help a child explain, sketch, or learn from an idea. It must not receive secrets or automatically modify, merge, publish, or deploy Linley on a child's instruction. All real changes require Dad's approval.
